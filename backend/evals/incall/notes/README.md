# Eval run notes

One file per eval run, named after its results folder (for example `2026-11-17T2306Z.md`).
`make eval-incall-report` and `make eval-incall-history` show it under "Notes and fixes" for
that run. Results folders are git-ignored; these notes are kept in git so the team keeps the
reasoning.

Suggested headings: **What we found**, **Decisions**, **Fixes made**, **Still open**.
